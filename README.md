# Умная таблица 1.0

Практическая работа № 6.2 Яндекс Практикума. Таблица на JavaScript показывает продажи и позволяет искать, фильтровать и сортировать записи. Проект собирается с помощью Vite.

## Возможности

- Поиск по дате, имени покупателя и имени продавца.
- Фильтрация по дате, покупателю, продавцу и диапазону сумм.
- Сортировка по дате и сумме покупки.
- Пагинация с выбором количества строк на странице.
- Сброс фильтров.

## Запуск

Из корня репозитория выполните:

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале. Для сборки проекта используйте `npm run build`.
